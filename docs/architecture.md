# 架构设计

cli → task pipeline → data/features/model/evaluation；各任务可依赖 common，common 不导入任务；Task 1 不依赖 Task 2。模型接口只处理已编码特征，模型不读取 CSV 或自行划分数据。每个函数详细输入输出见类型标注和 docstring。

## 两种训练路径

实验：原始 train → 固定 train/valid ID → 仅训练折 fit 特征 → 训练模型 → 验证指标 → 选择配置。测试集只用于预测及无标签 schema 检查，不以测试集拟合 IDF、编码器、缺失填充值。

最终：锁定配置/训练轮数 → 用完整 train 重新拟合特征与模型 → 保存完整 bundle → 新进程恢复 bundle → 预测 test → 按样例 ID 校验导出。两条路径必须分开；不能用全量训练模型反过来报告此前验证集成绩。

## Task 1：自主实现随机森林

先有多数类基线和自定义单树，再实现森林。CART 自行计算 Gini、候选分裂和停止条件；森林自行 bootstrap、子特征采样、概率聚合及类别权重。库只负责数组运算和 I/O。类别概率列固定为 1、2、3、4；最终输出整数 label。

随机森林是适合起步的候选方案，不是满分保证或课程指定模型。先用审计确认数据类型。数值缺失使用训练中位数，类别缺失与未知类别独立编码；编码不能从 label 学习。类别权重、缺失指示和树数通过固定验证集/交叉验证比较；Macro-F1 为主指标，补充逐类召回和混淆矩阵。随机森林没有 epoch，报告训练总时间和每棵树耗时，epoch 栏标 N/A 并说明。

## Task 2：Spark + 自定义稀疏评分回归

主路径：Spark 读取/清洗 → title/comment 分区编码 → 自定义哈希 TF-IDF + 元数据 → Spark 同步梯度训练 → 分布式评分/评估。CPU 即可，不强制 GPU。此选择兼顾可解释的算法贡献、可扩展性和课程工作量；线性模型上限需通过真实实验判断，再考虑更复杂模型。

title 与 comment 使用独立哈希空间（初始每个 65536 维），元数据在后续固定偏移追加，特征清单记录最终总维数。ID 不直接作为有序连续数值。元数据包括购买标记、log1p votes、文本长度、训练中用户/商品频率；时间特征须确认单位及合法范围。votes 可能存在预测时点可用性问题，需审计、披露并对比去除 votes 的实验。parent_prod_id 可作统计分组，不能凭空假设商品语义。

目标编码默认关闭。启用时，训练行用折外（OOF）用户/商品评分统计，验证/测试用整个当前训练折统计；未知实体回退训练先验。最终训练也必须为训练行生成 OOF 特征，预测使用全 train 聚合。不能直接按全表 rating 均值 join 回自身行。

训练：每 epoch 按稳定哈希划分固定小批次；每批只读广播参数，executor 流式计算数据梯度和样本数，treeAggregate 后 driver 按全局样本数归一化再加一次正则并更新。旧广播及时销毁。正则化不重复加到每个分区；空分区允许但全空批次须跳过或报错。缓存编码结果，必要时 checkpoint；不要每 epoch 重做文本预处理。

只允许收集维度受控的参数/梯度及标量统计；禁止全量评论、特征行、预测 collect/toPandas。特征维数、分区数与聚合缓冲大小决定 driver 内存，需在运行清单记录预算。大用户/商品映射保留为 Spark 表并 join。每 epoch 记录实测训练时间、损失、验证 RMSE；早停恢复最佳 epoch，最终重训使用锁定轮数。

预测输出有限连续实数，主评估 RMSE。作业允许回归，不能仅因原标签为整数就强制四舍五入；裁剪至 [1,5] 与否以验证结果和实际竞赛要求确定。样例 CSV 是输出列名的依据。

## 复现、计时和容错

保存配置、依赖锁、划分 ID、哈希版本、特征状态、模型参数、种子及训练日志。跨分区浮点归约可能有数值差异：固定分区策略，记录容差；不能承诺任意硬件位级一致。恢复模型后重新生成提交 CSV，并比较 ID 和预测结果。

离线时间从训练数据读取开始，到最终预处理状态和模型可保存为止，至少包含预处理与训练；单独披露是否包含 Spark 启动、模型落盘和验证。推理总时间覆盖全部测试记录读取、特征转换、模型预测和实际 materialize，注明是否包含模型加载；CSV 导出另计。Spark transformation 不能独立当作已完成的耗时测量。总离线时间使用端到端 wall-clock，不把含重叠的子阶段简单相加。

坏训练记录隔离并报告数量；坏测试记录不能静默丢弃，应修复或明确失败。ID 缺失/重复、特征 schema 变化、模型维数不符、NaN 或提交 ID 覆盖不完整均停止导出。临时写文件校验后原子替换。任务失败仍关闭 Spark、释放缓存。

## 报告证据

每次运行输出真实指标、硬件与耗时。固定划分比较基线/主模型；消融每次只改一个因素；多随机种子报告均值与波动（资源允许时）。Task 2 并行度实验固定数据和工作量，给出 1/2/4/8 等可用线程设置的耗时、加速比及 RMSE，而不是只声称使用了 Spark。
